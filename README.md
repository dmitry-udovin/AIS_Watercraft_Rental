# AIS_Watercraft_Rental / «Аренда плавательного средства»


📋 Описание проекта


 Цель проекта — спроектировать информационную систему для организации, предоставляющей услуги аренды и обучения на плавательных средствах (катера, лодки, катамараны, рафты, сапборды).
Проект включает полный цикл UML-моделирования: от функциональных требований (Use Case) до статической структуры системы (Class Diagram).
